実装指示書テンプレート

Claude Code に渡すための指示書の型です。ブラウザゲームを3本公開するまでに、実際に使っているものをそのまま置いています。

はじめに正直に書いておきます。この型は、1本目には要りません。
私も1本目は「ゲーム作れますか？ 暇つぶしになる簡単なやつ」の一言から始めています。この型が必要になるのは、3本目くらいからです。作りたいものが自分の中ではっきりしてきて、それを言葉にしきれずに困り始めたときに開いてください。

先に、いちばん効く1行だけ

全部を埋めなくて構いません。埋めるところが1箇所だけなら、ここです。

これだけでも効きます
完成の定義：初見の人が説明なしで開き、30秒以内に
「〈何をすると〉〈何が起きる〉」と気づく。

私が3本目で実際に書いたのは「初見の人が説明なしで開き、30秒以内に『自分が光ると周りが揃っていく』と気づく」でした。この1行を最初に決めておくと、途中で迷ったときに判断が全部ここに戻ってこられます。「この機能は要るか？」ではなく「これは完成の定義を強くするか？」で決められるようになります。

テンプレート全文

〈　〉で囲った部分を自分の企画に置き換えて、そのまま Claude Code に貼ってください。中に書いてあるのは「そこに何を書けばいいか」の説明です。

## 0. Claude Code への前提指示
- 出力は `〈フォルダ名〉/index.html` 1ファイルのみ。HTML / CSS / JS を同梱する
- npm、CDN、外部フォント、外部画像 すべて禁止。オフラインで動くこと
- 新しい依存を追加しない
- 動作確認はローカル起動し、モバイルエミュレータ（iPhone 縦）で行う
- 工程は §7 の通りに分ける。1工程やったら止まって報告する。
  まとめて全部やらない
- 各工程の最後に、次のセッション用の再開メモを1行で出す

## 6. 受け入れ基準
工程②終了時：
- [ ] 〈操作〉を続けると、〈秒数〉以内に〈起きてほしいこと〉が起きる
- [ ] 〈操作〉をやめると、自然に元に戻る
- [ ] 放置しても勝手に〈起きてほしいこと〉が起きない

工程③終了時：
- [ ] 実機 iPhone、縦持ち、片手で1回通せる
- [ ] 機内モードで動く
- [ ] 音量ゼロで成立する
- [ ] localStorage を空にした初回起動で落ちない
- [ ] 画面回転・バックグラウンド復帰で状態が壊れない

---
## 7. 工程
1工程ごとに止まって報告する。

| 工程 | やること | やらないこと | 成果物 |
|---|---|---|---|
| ② コア | §3 だけ | 演出・音・保存・その他すべて | 遊べるが素っ気ない版 |
| ②' 調整 | §3 の数値を触り、受け入れ基準を満たす | 新機能の追加 | 数値の確定 |
| ③ 形にする | 開始と終了、結果画面 | 演出・音 | 1回が完結する版 |
| ④ 化粧 | §5 の見た目と音、保存 | 新しい遊びの追加 | 完成版 |
| ⑤ 公開 | OGP画像、meta、トップページへの追加 | ― | リリース |

工程②が受け入れ基準を満たさない場合、③へ進まずに②'に戻る。
コアが気持ちよくないものは、演出を足しても救えない。

## 8. 迷ったときの判断基準
1. 追加しようとしている要素は〈完成の定義〉を強くするか？
   しないなら捨てる
2. 説明文が必要になったら、それは仕組みが複雑すぎる証拠
3. 数字を出したくなったら、別の言葉に置き換えられないか考える

使うときの4つのコツ

1. 「やらないこと」を必ず書く

この型でいちばん効くのは、実は工程表の「やらないこと」の列です。書かないと、Claude Code は親切なので全部いっぺんに作ってくれます。そして全部いっぺんに出てくると、どこが悪いのか分からなくなります。

2. 1工程ごとに止めさせる

「1工程やったら止まって報告する。まとめて全部やらない」の一文を §0 に入れておくかどうかで、進み方がまるで変わります。止めさせないと、確認しないまま先へ進んでしまいます。

3. コアが良くなければ、先に進まない

工程②で「気持ちいい」が出ていないのに③へ進むと、あとで戻れなくなります。演出は、面白くないものを面白くはしてくれません。ここだけは、自分に厳しくしたほうが結果的に早いです。

4. 埋まらない欄は、空のままでいい

全部埋めようとすると、書くこと自体が目的になります。埋まらない欄は、まだ決まっていないということなので、そのまま渡して「ここは決まっていません。案をください」と書けば大丈夫です。

この型がどうやってできたのかは、記事に全部書いています。
最初の「ゲーム作れますか？」から、この指示書にたどり着くまでの記録です。
